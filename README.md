# jotace content planner

Proyecto chico para planificar contenido de redes de **jotace.**

- `src/pillars.js`: pilares de contenido (educar, mostrar, conectar, vender)
- `src/formats.js`: formatos por red
- `src/calendar.js`: arma el calendario rotando pilares y formatos
- `src/captions.js`: genera captions con CTA y hashtags

```bash
npm start   # muestra un calendario de 2 semanas y un caption de ejemplo
npm test    # corre los tests
```
